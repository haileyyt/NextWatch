# Contributing

NextWatch now has a local Cycle 2 prototype using fictional data. Suggestions about preference collection, recommendation evaluation, accessible UI design, and suitable data sources are welcome.

Open an issue describing the problem and a small proposed improvement. For code contributions, discuss the scope first, keep the change focused, explain how you checked it, and include meaningful tests where behavior changes. Run `python -m unittest discover -s tests -v` before proposing changes. Setup and demo commands are in README.md.

Only contribute material you have the right to share. Do not upload account credentials, personal viewing histories, or unlicensed datasets. Use synthetic examples for bug reports.
