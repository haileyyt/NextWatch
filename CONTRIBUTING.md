# Contributing to NextWatch

NextWatch is currently in the planning stage. Feedback and suggestions are welcome, particularly in the following areas:

- Recommendation signals and evaluation.
- Suitable show datasets and their reuse terms.
- Preference collection and interface design.
- Clear explanations for recommendations.
- Accessibility and ease of use.

## Suggesting an improvement

Open an issue describing:

1. The problem or question.
2. Your proposed improvement.
3. How it would help users or improve the project.

Keep suggestions focused on the initial project scope where possible.

## Contributing code

Before starting a substantial change, open an issue to discuss the approach.

Keep pull requests focused, explain what changed and why, and describe how you checked the resulting behavior.

Development and test instructions will be added when the first executable prototype is available.

## Data and privacy

Use synthetic examples when reporting problems.

Do not submit account credentials, API keys, personal viewing histories, or datasets you do not have permission to share.

Third-party material must retain its applicable license and attribution.
